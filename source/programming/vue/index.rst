===============
Vue3
===============

**适用版本**：Vue 3 + Vite 7 + Node.js 20/22 LTS。

创建项目
=========

.. code-block:: bash

   npm create vite@latest .
   npm install --registry https://registry.npmmirror.com
   npm run dev
   npm run build
