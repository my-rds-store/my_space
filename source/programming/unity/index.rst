Unity
==============

**当前版本**：Unity 6（6000.x）或 2022 LTS。

* `Unity Hub <https://unity.com/download>`_
* `Unity 文档 <https://docs.unity3d.com/>`_
* `Unity Learn <https://learn.unity.com/>`_
* `Asset Store <https://assetstore.unity.com/>`_


* 快捷键
    * `ctrl + D` 复制
    * `F` 聚焦
    * `alt+左键`  视角围绕选中物体旋转
