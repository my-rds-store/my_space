待办事项
############

本页记录个人待办事项，按状态分为「进行中」「待办」「已完成」三部分。

**标记约定**

* [ ] 未完成
* [x] 已完成

新增事项时，在对应小节下写一行列表项；完成后把方括号里的空格改成字母 x，
再把该条移动到「已完成」小节。需要补充说明时，可在事项下缩进写备注或链接。

**格式示例**

.. code-block:: text

    * [ ] 事项描述
    * [x] 已完成的事项
